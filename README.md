## Overview

The **Big Bang–Supernova Infinite Cycle Theory** proposes a novel, scale-relative cosmological model in which supernovae and Big Bangs are fundamentally the same type of event—observed from different levels of cosmic scale.

This theory suggests that every supernova could represent the genesis of a new universe nested within a higher-scale cosmological framework, forming an infinitely recursive, fractal-like structure. It integrates principles from:

- **Quantum Mechanics** (entanglement, quantum time, tunneling)
- **Thermodynamics** (entropy as transformation across scales)
- **Relativity and Perception of Time**
- **Biological analogies** (life-death-rebirth cycles of universes)

This repository archives the current theory document and will serve as a base for future development, including:

- Mathematical modeling  
- Entropic simulations  
- Community feedback & version tracking
